# Computational Geometry

<img src="https://m.media-amazon.com/images/I/61ycMCtURpL._SL1079_.jpg" alt="Book Cover" width="250"/>

A C++23 library implementing algorithms from *Computational Geometry: Algorithms and Applications* by Mark de Berg, Otfried Cheong, Marc van Kreveld and Mark Overmars. Includes implementations of convex hulls, polygon triangulation, Delaunay triangulation, Voronoi diagrams, point location, intersection detection, motion planning, range queries and more.

## Building

Requirements:
- CMake 3.21+
- C++23 compiler (Clang 18+, GCC 14+)
- Eigen
- Catch2 v3.8.1 (tests only, automatically fetched)
- Qt 6 Widgets (demos only)

## Demos

This repository includes several demo applications designed to visualize the results of various algorithms, such as:

- Delaunay triangulation
- Voronoi diagrams
- Quad tree meshes
